PRUEBA DE CONEXION REAL - Fuentes de datos

1. Ejecuta supabase_prueba_conexion.sql en Supabase SQL Editor.
2. Sustituye pages/2_Fuentes_de_datos.py por 2_Fuentes_de_datos.py.
3. Sustituye bridge.py por bridge.py del paquete.
4. GitHub Actions: compila el conector Windows, instala la versión nueva y reinicia la tarea ConsultaPreciosConectorLAN.
5. Verifica http://127.0.0.1:8765/health y pulsa Probar conexion en Fuentes de datos.

No modifica app.py ni el verificador de Supabase. La prueba abre la base de datos guardada y ejecuta SELECT DB_NAME(), 1.
Por ahora esta prueba soporta SQL Server; otras bases requieren adaptadores.
No publiques el puerto 8765 a Internet.

Política de privacidad

Consulta de Precios · Última actualización: 23 de octubre de 2026

Consulta de Precios es la aplicación interna que el negocio usa para mostrar precios de productos en sus verificadores y en la consulta desde el celular. Esta página explica qué datos usa y cómo.

Datos de Google que usa la aplicación

Si el administrador conecta una cuenta de Google, la aplicación pide acceso de solo lectura a Google Drive y Google Sheets (drive.readonly y spreadsheets.readonly). Lo usa únicamente para:

  • leer el archivo de precios que el administrador elige (código de barras, nombre y precio de cada producto);
  • mostrar el nombre y el correo de la cuenta conectada, para que el administrador sepa cuál es.

La aplicación no modifica, no borra y no comparte archivos de Google Drive, y no lee otros archivos que el elegido por el administrador.

Qué se guarda

  • El permiso de acceso de Google (refresh token) se guarda cifrado en la base de datos de la aplicación, solo para volver a leer el archivo de precios.
  • Los precios leídos se usan para responder consultas y se copian a los verificadores de la tienda para que funcionen sin internet.
  • Se registran las consultas de precio (código consultado, si se encontró, fecha) para mejorar el inventario. No se registran datos personales de los clientes.

Uso de los datos de Google

El uso que hace esta aplicación de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado. Los datos no se venden, no se usan para publicidad y no se entregan a terceros.

Cómo quitar el acceso

El administrador puede desconectar la cuenta en la aplicación (Precios > Google Drive / Sheets > Desconectar cuenta de Google) o en cualquier momento desde myaccount.google.com/permissions. Al desconectar, se borra el permiso guardado.
